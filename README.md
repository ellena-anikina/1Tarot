# Сайт раскладов Таро

Расклады Таро с трактовкой от ИИ. Таро здесь — инструмент саморефлексии, а не гадание (подход в духе Biddy Tarot):
карты помогают яснее увидеть ситуацию, а каждая трактовка заканчивается вопросом для размышления.

Название «Аркана» — **рабочее**. Меняется в одном месте: `src/config/site.ts`.

---

## Как запустить у себя

**Проще всего:** дважды щёлкните `start.bat`. При первом запуске он установит зависимости (минута-другая), потом откроет сайт в браузере.

**Через терминал:**

```bash
npm install      # один раз
npm run dev      # запустить сайт
```

Откройте http://localhost:3000. Если порт 3000 занят другим проектом, Next.js выберет соседний (например, 3001) и напишет адрес в терминале.

Нужен Node.js 20.9 или новее (https://nodejs.org).

## Где указать API-ключ

Единственный файл, который нужно заполнить, — **`.env.local`** в корне проекта. В нём подробные пояснения.

1. Вставьте ключ в строку `AI_API_KEY=`.
2. Если ключ от Claude (начинается с `sk-ant-`), OpenRouter (`sk-or-`) или Gemini (`AIza`), больше ничего не нужно — провайдер определится сам.
3. Для других провайдеров укажите `AI_PROVIDER` и `AI_MODEL` (варианты и примеры — в самом файле).
4. Перезапустите сервер (Ctrl+C, затем `npm run dev`).

Пока ключа нет, сайт работает в **демо-режиме**: расклад, анимации, дневник, страницы карт — всё настоящее, а трактовка собирается из описаний карт. Вверху трактовки будет пометка «Демо-режим» с подсказкой.

Если ключ указан, но ИИ не ответил (неверный ключ, кончились деньги, сеть), сайт попробует запасные модели (если они указаны, см. ниже), а если не ответят и они — посетитель увидит базовую трактовку. При локальной разработке над трактовкой видна понятная причина ошибки.

### Какие провайдеры поддерживаются

| `AI_PROVIDER` | Что это | Модель по умолчанию |
|---|---|---|
| `anthropic` | Claude, официальный SDK Anthropic | `claude-opus-5-5` |
| `openai` | OpenAI | `gpt-5-mini` |
| `openrouter` | Один ключ — сотни моделей разных компаний | нужно указать |
| `deepseek` | DeepSeek | `deepseek-chat` |
| `gemini` | Google Gemini (OpenAI-совместимый режим) | нужно указать |
| `yandex` | YandexGPT и Alice AI (Yandex AI Studio), оплата в рублях | нужно указать: `gpt://<ID каталога>/…` |
| `cloudru` | GigaChat и открытые модели (Cloud.ru Foundation Models), оплата в рублях | нужно указать |
| `ollama` | Модель на вашем компьютере, без ключа | нужно указать |
| `custom` | Любой OpenAI-совместимый сервис (нужен `AI_BASE_URL`) | нужно указать |

**О цене.** По умолчанию для Claude стоит самая сильная модель, Opus 5.5. Расклад на три карты на ней стоит примерно 2–4 цента (зависит от длины ответа). `claude-haiku-5-5` примерно в 40 раз дешевле, `claude-sonnet-5-5` — середина. Перед запуском для посетителей стоит сравнить трактовки разных моделей на нескольких одинаковых раскладах. Выбор модели — строка `AI_MODEL`. Цены провайдеров меняются, сверяйтесь с их сайтами.

**Защита бюджета.** `READINGS_PER_HOUR` ограничивает число ИИ-трактовок в час с одного адреса (по умолчанию 20). Сверх лимита показывается базовая трактовка.

**Глубина размышлений.** `AI_EFFORT` — `low`, `medium` или `high`: насколько тщательно модель думает перед ответом. Строка действует сразу на основную и запасные модели.
- Claude при прямом подключении получает глубину всегда; если строка пустая — `low`.
- Остальным моделям она уходит, только если строка заполнена (параметр `reasoning_effort`). Модели, которые не умеют размышлять, его не замечают, а если провайдер его отклоняет, сайт повторяет запрос без него.
- Чем глубже, тем позже первые слова и дороже ответ. На пробе через tokenator Gemini на `high` начала писать только через 49 секунд и потратила в 13 раз больше токенов.
- При глубине выше `low` сайт ждёт первого ответа модели до 40 секунд, а не 15: пока модель думает, многие провайдеры молчат.

**Если сервер или оплата в России.** Anthropic, OpenAI и Google официально не работают с Россией. Работают российские сервисы с оплатой в рублях — Yandex AI Studio (`yandex`: YandexGPT, Alice AI и открытые модели) и Cloud.ru (`cloudru`: GigaChat и открытые модели), а также модель на своём компьютере (`ollama`). GigaChat напрямую через API Сбера пока не подключается: там вместо постоянного ключа нужен токен, который обновляется каждые 30 минут, — используйте Cloud.ru.

### Запасные модели

Кроме основной модели можно указать до двух запасных — блоки `AI_*_2` и `AI_*_3` в `.env.local`, они заполняются так же. Если основная модель не ответила, сайт сам по очереди пробует запасные; если не ответил никто — показывает базовую трактовку.

- **Когда переключается:** ключ не принят, кончились деньги, модель не найдена, сервис недоступен или прислал пустой ответ, модель молчит 15 секунд (модель на своём компьютере — 3 минуты). Если модель сначала «размышляет» (так устроены MiniMax, DeepSeek-R и другие), это не молчание: её первых слов сайт ждёт до 40 секунд. Столько же он ждёт и молчащую модель, если в `AI_EFFORT` задана глубина выше `low`.
- **Когда не переключается:** если ответ оборвался на середине — к уже показанному тексту вторую трактовку не приклеиваем, посетитель видит просьбу повторить расклад. И если модель отказалась отвечать по существу: это не сбой, и другой моделью его не обходим.
- **Как заметить переключение:** посетитель его не видит. При локальной разработке над трактовкой появляется пометка, какая модель не ответила и почему; на сервере каждое переключение пишется в журнал (строки `[reading]`).
- **Что брать запасной:** другой сервис, а не второй ключ того же — у другого сервиса свой баланс и свои сбои. На каждый ключ стоит поставить лимит расходов в кабинете провайдера.

### Сравнение моделей: журнал раскладов

При локальной разработке (`npm run dev`) каждый ИИ-расклад записывается в `logs/readings.jsonl` — по строке на расклад: вопрос, карты, какая модель отвечала, через сколько секунд пошли первые слова, сколько длился ответ, сколько токенов ушло на входе и выходе (у моделей, которые «размышляют», — и на размышления), полный текст ответа и причина сбоя, если модель не ответила. Над трактовкой в подписи «Отвечает ИИ» видны время и токены каждого ответа, а у «размышляющих» моделей — сколько секунд модель думала, прежде чем начать писать. В терминале — та же строка. Если задана глубина размышлений (`AI_EFFORT`), подпись показывает и её. Когда модель её не применила, там будет «признаков размышлений нет» или «глубину размышлений провайдер не принял».

- Модель можно менять прямо во время работы `npm run dev`: исправьте `AI_MODEL` в `.env.local` и сохраните файл — следующий расклад уйдёт уже новой модели (в терминале появится `Reload env: .env.local`).
- Журнал только на вашем компьютере: в git не попадает, на хостинге не пишется — в нём вопросы целиком.
- Чтобы получить сравнение моделей по скорости, токенам, цене и качеству ответов, попросите Claude разобрать журнал.
- Для частых тестов поднимите `READINGS_PER_HOUR` в `.env.local` — иначе после 20 раскладов за час покажется базовая трактовка.

## Оплата

Сейчас работает **тестовая оплата**. Весь путь посетителя настоящий, но вместо банка открывается тестовая страница, и деньги не списываются.

**Что видит посетитель:**

1. Цена видна уже при выборе расклада. «Подсказка» (1 карта) бесплатна раз в день, «Разбор ситуации» (3 карты) стоит 199 ₽, «Глубокий разбор» (Кельтский крест, 10 карт) — 499 ₽. Вторая подсказка за день стоит 99 ₽.
2. Перемешать колоду, вытянуть карты и прочитать их значения можно бесплатно.
3. Когда карты легли, вместо трактовки появляется экран оплаты: что войдёт в трактовку и кнопка «Оплатить 199 ₽».
4. Посетитель уходит на страницу оплаты (сейчас это тестовая `/oplata`), платит и возвращается. Сверху стоит «Оплата прошла», и трактовка сразу начинает писаться. В дневник расклад сохраняется вместе с номером заказа.
5. Если посетитель отказался от оплаты или банк отклонил платёж, он возвращается к тем же картам и видит понятное сообщение. Если он закрыл страницу, при следующем визите над формой появится напоминание «Оплата расклада не завершена».
6. Деньги берутся только за пришедшую трактовку. При оплате картой сумма сначала блокируется, а списывается, когда трактовка готова (холдирование). СБП блокировать не умеет: деньги приходят сразу, а если трактовка не пришла, их можно вернуть.
7. Если на оплаченный расклад ИИ не ответил, появятся две кнопки. «Повторить трактовку» — бесплатно, по той же оплате. «Отменить оплату» (для карты) или «Вернуть деньги» (для СБП) — если трактовка больше не нужна.

**Где что менять:**

- Цены, бесплатный лимит и рекомендуемый расклад — `src/config/pricing.ts`.
- Чтобы выключить оплату и сделать все расклады бесплатными, задайте `PAYMENTS_MODE=off` в `.env.local` и перезапустите сервер. Без этой строки работает тестовая оплата (`mock`).
- Каждый шаг тестовой оплаты виден в терминале сервера строкой `[payment] …`: оплата прошла или сумма заблокирована, «трактовка готова, списано», «блокировка снята», «возврат».

**Бесплатная подсказка — раз в день.** Подсказка засчитывается, как только уходит запрос трактовки. Поэтому уйти со страницы посреди ответа и получить её снова не получится. Если ИИ не ответил или пропала связь, подсказка возвращается. Вкладки сверяются между собой.

Лимит считает браузер: в другом браузере или в режиме инкогнито подсказка снова будет бесплатной. На этот случай сервер пропускает не больше трёх бесплатных подсказок в сутки с одного адреса (`FREE_PER_IP_PER_DAY`). Это не одна, потому что под одним адресом бывают семья в одной сети Wi-Fi или клиенты мобильного оператора. Полностью закрыть лазейку можно только входом по почте или телефону. Счётчик сервера сбрасывается при его перезапуске.

**Защита.** Цену назначает сервер, а не страница. Подтверждение оплаты подписано секретом сервера и привязано к вопросу и выпавшим картам, поэтому одной оплатой нельзя открыть другой расклад. На хостинге задайте `PAYMENTS_SECRET`: длинную случайную строку.

**Что нужно для настоящей оплаты.** Владелица будет самозанятой. Нужен платёжный сервис, который:
- работает с самозанятыми;
- принимает СБП и карты;
- сам отправляет чеки в «Мой налог»;
- умеет холдирование по картам;
- принимает тематику сайта.

Главный кандидат — Робокасса: чеки в «Мой налог» отправляет её сервис «Робочеки СМЗ», холдирование по картам есть. Доступно ли холдирование самозанятым, нужно уточнить. По сообщениям пользователей, ЮKassa с 29.12.2025 перестала передавать чеки самозанятых в «Мой налог». Официально это не проверено. Яндекс Пэй запрещает «трансцендентные услуги».

При возврате денег самозанятой нужно аннулировать чек в «Мой налог» с причиной «Возврат средств».

На сайте должны быть оферта, политика конфиденциальности, контакты и условия возврата.

В коде (`src/lib/payments/server.ts`) нужно заменить четыре вещи на запросы к API сервиса:
- тестовую страницу — страницей сервиса;
- проверку подписи — запросом статуса платежа;
- списание и отмену блокировки — его методами;
- возврат — его методом.

Путь посетителя менять не придётся.

## Две темы оформления — выберите одну

Сейчас на сайте две темы, переключатель — справа в шапке:

- **«Ночной бархат»** — тёмная, по умолчанию;
- **«Светлая бумага»** — светлая.

Когда выберете, скажите Claude «оставляем тему …» — или удалите сами: блок ненужной темы в `src/app/globals.css`, переключатель `src/components/ThemeToggle.tsx` и его вызов в `src/components/SiteHeader.tsx`, а в `src/app/layout.tsx` поставьте нужную тему в `data-theme`.

## Карты

- Иллюстрации — колода Райдера–Уэйта 1909 года (Памела Колман Смит), общественное достояние, сканы с Wikimedia Commons.
- Английские подписи срезаны, рамку и **русскую подпись** рисует сам сайт. Все 78 карт лежат в `public/cards/640` и `public/cards/320`.
- Пересобрать изображения: `npm run cards:prepare` — скрипт скачает сканы и обработает их заново.
- Значения карт (ключевые слова, прямое и перевёрнутое положение, любовь, работа, совет, вопрос для размышления): `src/data/meanings/`.
- Как часто выпадают перевёрнутые карты: `REVERSED_PROBABILITY` в `src/config/site.ts` (сейчас 30%).

## Блог

Статьи — обычные файлы Markdown в `content/blog/`. Чтобы добавить статью, создайте новый `.md` по образцу:

```markdown
---
title: "Заголовок статьи"
description: "1–2 предложения для поисковиков и списка статей."
date: 2026-11-20
keywords:
  - ключевая фраза
---

Текст статьи. ## Подзаголовки, списки, [ссылки на карты](/karty/zvezda).
```

Адрес статьи = имя файла: `content/blog/moya-statya.md` → `/blog/moya-statya`. Статья сама появится в блоге, на главной, в карте сайта и в «Читать дальше».

## Публикация

- **Vercel** (проще всего): подключите проект и задайте переменные из `.env.example` в настройках. Бесплатный тариф Hobby — только для некоммерческих проектов: без оплаты от посетителей и рекламы.
- **Тестовая версия** на временном адресе: задайте `SITE_NOINDEX=1` — поисковики не добавят её страницы в выдачу, и временный адрес потом не будет конкурировать с настоящим доменом. Переменная действует со следующей сборки (на Vercel — Redeploy). На настоящем домене её не задавайте.
- **Свой сервер (VPS):** `npm install && npm run build && npm start` (порт 3000), перед ним — nginx с HTTPS.

Ключ хранится только на сервере и в браузер посетителя не попадает.

## Устройство проекта

```
.env.local                  ← API-ключ и настройки ИИ
start.bat                   ← запуск двойным кликом
content/blog/               ← статьи блога (Markdown)
public/cards/               ← изображения карт
scripts/                    ← подготовка карт и картинки-превью
src/config/site.ts          ← название, описание, вероятность перевёрнутых карт
src/config/pricing.ts       ← цены раскладов и бесплатный лимит
src/data/                   ← колода, значения карт, расклады, темы
src/lib/ai/                 ← подключение моделей, инструкция для ИИ, демо-трактовка
src/lib/payments/           ← оплата: заказы, проверка оплаты, расклады, ждущие оплаты
src/app/                    ← страницы: главная, /karty, /blog, /dnevnik, тестовая /oplata, API /api/reading и /api/payments
src/components/reading/     ← стол расклада: колода, веер, позиции, экран оплаты, трактовка
```

Дневник раскладов хранится только в браузере посетителя (localStorage) — без регистрации и без базы данных.
