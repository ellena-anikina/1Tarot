# Контекст проекта для Claude

Сайт раскладов Таро на Next.js 16 (App Router, TypeScript, CSS Modules, Motion). Владелица — Елена. Общаться по-русски.

## Принятые решения (не менять без согласования)
- Подход: Таро как инструмент саморефлексии и самопознания, не гадание (ориентир по смыслу — biddytarot.com, не по дизайну). Никаких «предсказаний судьбы»; трактовка заканчивается вопросом для размышления.
- Язык сайта — только русский. Обращение на «вы», без форм, выдающих пол собеседника. Если в трактовке ИИ без рода не обойтись — женский род: это основная аудитория (решено 16.11.2026, `src/lib/ai/prompt.ts`).
- Колода — классика Райдера–Уэйта 1909 года с русскими подписями: сайт рисует рамку и плашку сам, английские подписи срезаны скриптом `scripts/prepare-cards.mjs`.
- Тема одна — светлая («Светлая бумага»), переключателя тем нет (решено 20.11.2026). Тёмно-синий с золотом читался как эзотерика, а сайт — о саморефлексии; переключатель отвлекал от расклада. Рубашка карт остаётся тёмной: колода — физический предмет. Превью ссылки (`public/og.png`, `scripts/make-og.mjs`) тоже светлое.
- Название — «Нежное Таро» (решено 18.11.2026; «Аркана» отпала: ею уже называются другие сайты таро, а её домены заняты). Домен — nezhnoetaro.ru (работает с 19.11), он же адрес по умолчанию в `src/config/site.ts`. Подписи без повтора «Таро» (согласовано 19.11): заголовок главной «Нежное Таро — онлайн-расклад с вдумчивой трактовкой», превью ссылки «Нежное Таро — расклады для размышлений».
- Модель ИИ (решено 16.11.2026 по слепому сравнению, DeepSeek победил 5 из 6): основная — DeepSeek V4.1 Flash, запасная — Claude Opus 5.5. Обе пока через тестового посредника tokenator. Сайт поддерживает Claude (официальный SDK) и любых OpenAI-совместимых провайдеров, настройки в `.env.local` и в переменных Vercel. До двух запасных моделей (`AI_*_2`, `AI_*_3`): если основная не ответила, сервер сам пробует их по очереди (`src/app/api/reading/route.ts`). Без ключа — демо-режим.
- Аудитория (Россия или нет) пока не определена: в настройках держать и зарубежных провайдеров (Claude, OpenAI, Gemini и др.), и российских (Yandex AI Studio, Cloud.ru с GigaChat).
- Владелица просит задавать вопросы, а не додумывать, когда решение за ней.
- Оплата (решено 12.11.2026). Владелица будет самозанятой. Способы оплаты — СБП и карта. Платят после того, как карты легли. Деньги берутся только за пришедшую трактовку: картой сумма блокируется и списывается после трактовки, по СБП — возврат, если трактовка не пришла. Сейчас оплата тестовая: `PAYMENTS_MODE=mock`, страница `/oplata`, логика в `src/lib/payments/`.

- Цены (решено 12.11.2026, `src/config/pricing.ts`):
  - «Подсказка» (1 карта) — бесплатно раз в день, сверх этого 99 ₽;
  - «Разбор ситуации» (3 карты) — 199 ₽;
  - «Глубокий разбор» (Кельтский крест) — 499 ₽.

  Бесплатную подсказку считает браузер: она засчитывается, когда уходит запрос трактовки. Сервер дополнительно пропускает не больше `FREE_PER_IP_PER_DAY` (3) подсказок в сутки с одного адреса.

## Ждёт решения владелицы
- Платёжный сервис. Кандидат — Робокасса: чеки самозанятых в «Мой налог», холдирование по картам. До подключения спросить письменно, примет ли сервис тематику сайта.
- Веб-аналитика, чтобы видеть воронку оплаты (предложена Яндекс Метрика с целями). Нужен номер счётчика и уведомление о cookie.
- Хостинг для запуска с оплатой. Vercel не подходит: Hobby только для некоммерческих проектов, а свои домены на Vercel в 2025–2026 часто не открываются из российских сетей. Кандидат — Timeweb Cloud (App Platform из GitHub или сервер от 550 ₽/мес с 2 ГБ памяти). Виртуальный «Хостинг для сайта» не годится: там нет Node.js. У Елены уже есть хостинг на Timeweb, тариф уточнить.

## Как проверять
- `npm run dev` (порт 3000), `npx tsc --noEmit`, `npm run build`.
- Журнал ИИ-раскладов при `npm run dev`: `logs/readings.jsonl` (вопрос, карты, модель, скорость, токены, текст ответа, причина сбоя) — по нему сравниваем модели (`src/lib/ai/reading-log.ts`). На хостинге не пишется.
- Скилл `ui-ux-pro-max` установлен в `.claude/skills/` (база UI/UX-знаний).
