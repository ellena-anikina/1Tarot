# Контекст проекта для Claude

Сайт раскладов Таро на Next.js 16 (App Router, TypeScript, CSS Modules, Motion). Владелица — Елена. Общаться по-русски.

## Принятые решения (не менять без согласования)
- Подход: Таро как инструмент саморефлексии и самопознания, не гадание (ориентир по смыслу — biddytarot.com, не по дизайну). Никаких «предсказаний судьбы»; трактовка заканчивается вопросом для размышления.
- Язык сайта — только русский. Обращение на «вы», без форм, выдающих пол собеседника.
- Колода — классика Райдера–Уэйта 1909 года с русскими подписями: сайт рисует рамку и плашку сам, английские подписи срезаны скриптом `scripts/prepare-cards.mjs`.
- Две темы для выбора: «Ночной бархат» (night) и «Светлая бумага» (paper). После выбора невыбранную удалить.
- Название «Аркана» — рабочее, владелица решит позже (`src/config/site.ts`).
- Модель ИИ пока не выбрана: поддержка Claude (официальный SDK) и любых OpenAI-совместимых провайдеров, настройки в `.env.local`. До двух запасных моделей (`AI_*_2`, `AI_*_3`): если основная не ответила, сервер сам пробует их по очереди (`src/app/api/reading/route.ts`). Без ключа — демо-режим.
- Аудитория (Россия или нет) пока не определена: в настройках держать и зарубежных провайдеров (Claude, OpenAI, Gemini и др.), и российских (Yandex AI Studio, Cloud.ru с GigaChat).
- Владелица просит задавать вопросы, а не додумывать, когда решение за ней.

## Как проверять
- `npm run dev` (порт 3000), `npx tsc --noEmit`, `npm run build`.
- Журнал ИИ-раскладов при `npm run dev`: `logs/readings.jsonl` (вопрос, карты, модель, скорость, токены, текст ответа, причина сбоя) — по нему сравниваем модели (`src/lib/ai/reading-log.ts`). На хостинге не пишется.
- Скилл `ui-ux-pro-max` установлен в `.claude/skills/` (база UI/UX-знаний).
